# Git Practice

Учебный проект для изучения Git: коммиты, ветки, слияния, разрешение конфликтов и работа с удалённым репозиторием.

## Структура
- src — исходный код
- test — тесты
- docs — документация
- .gitignore — исключает временные файлы (*.tmp, *.log), локальные настройки (.env) и папки IDE

## Что отработано
- Коммиты с осмысленными сообщениями
- Создание веток и переключение между ними
- Слияние веток и разрешение конфликта (см. conflict.txt)
- Отмена коммита через revert
- Игнорирование файлов через .gitignore
- Тег версии v1.0.0
- Работа с удалённым репозиторием (push/pull)

## Практическая часть
Учебная функция входа Login feature реализована в ветке feature/login и влита в main. Файл login.txt в папке src содержит описание проверки имени пользователя и пароля. Файл conflict.txt в папке docs — результат ручного разрешения конфликта слияния.
